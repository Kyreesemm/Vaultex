# Vaultex

Vaultex is a private, encrypted workspace for text notes, Markdown documents, passwords, tokens, account credentials, and cryptographic keys. It is designed as a local-first vault with a focused interface for keeping sensitive information organized and protected.

The application is planned for Windows, Linux, and Android. The user interface is built with HTML, CSS, and JavaScript, while the application shell and backend are built entirely with Rust using Tauri 2 for a lightweight cross-platform desktop and mobile application.
